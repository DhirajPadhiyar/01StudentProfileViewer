# 01-StudentProfileViewer

A beginner-friendly ASP.NET Core MVC project that displays student profile information dynamically using Controllers, Models, Razor Views, and simple CSS styling.

---

# Features

* Dynamic student profile display
* Multiple student information rendering
* Clean UI design
* Razor Syntax usage
* MVC architecture basics
* Simple custom CSS styling

---

# Technologies Used

* ASP.NET Core MVC
* C#
* Razor Views
* HTML
* CSS

---

# Concepts Covered

* MVC Architecture
* Controllers
* Models
*  

  Student List using Loops

    
* Razor Syntax
* Dynamic Data Rendering
* Object Creation
* Passing Data from Controller to View
* Basic CSS Styling

```text
Controller → Model/Object → Razor View → Dynamic UI
```
